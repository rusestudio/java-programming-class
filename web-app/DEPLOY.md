# Deploy to Railway or Render

For full server support with JDK:

1. Sign up at railway.app or render.com
2. Connect your GitHub repo
3. Set build command: `npm install`
4. Set start command: `npm start`
5. Railway/Render provide Node.js with binaries support

# Alternative: Static Frontend Only

Deploy only the frontend to Vercel/Netlify, remove backend features.
